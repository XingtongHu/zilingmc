📜 PixelCraft Minecraft 服务器规则

最后更新时间：2026年8月16日
服务器版本：Minecraft Java Edition 26.2
服务器地址：pixel.furrycraft.cn

一、基本规则

1.1 玩家行为

  1. 不得使用侮辱、歧视、骚扰等言论攻击其他玩家。
  2. 不得恶意刷屏、发送广告或发布无关内容。
  3. 不得冒充管理员、服务器工作人员或其他玩家。
  4. 不得利用游戏机制恶意影响其他玩家的正常游戏体验。

1.2 游戏公平

  1. 禁止使用 X-Ray、透视、自动挖矿等破坏游戏公平性的工具。
  2. 禁止利用恶性 Bug 获取不正当收益。
  3. 禁止使用脚本、宏或自动化程序进行违规操作。

二、建筑与领地

2.1 建筑保护

  1. 禁止未经允许破坏其他玩家建筑。
  2. 禁止未经允许拿取其他玩家箱子、熔炉、潜影盒等容器中的物品。
  3. 禁止恶意占用其他玩家建筑附近区域。
  4. 禁止在他人建筑附近进行恶意骚扰。

2.2 领地规则

领地系统：√ 有

请使用基础的木锄头，圈好两地的边距，然后输入 /res create 领地名 来创建您的领地。

三、资源与经济

3.1 资源获取

  1. 禁止利用 Bug 无限复制物品。
  2. 禁止恶意破坏公共资源。
  3. 禁止恶意刷取服务器经济。
  4. 允许自动化农场：√ 是

3.2 玩家交易

  1. 玩家之间可以自由交易。
  2. 玩家交易原则上由双方自行确认。
  3. 因玩家个人交易失误造成的损失：腐竹无权干预，十分抱歉。
  4. 禁止诈骗行为：√ 是

四、服务器聊天

4.1 聊天规范

禁止以下行为：

  1. 人身攻击
  2. 恶意刷屏
  3. 广告
  4. 恶意引战
  5. 散布虚假信息

五、管理员与玩家

5.1 管理员权限

  1. 处理玩家违规行为。
  2. 调查作弊、Bug 利用等问题。
  3. 在必要情况下暂时限制违规玩家的游戏权限。
  4. 对服务器异常情况进行处理。
  5. 连接服务器后台的远程控制。

5.2 管理员行为

  1. 管理员不得滥用管理权限。
  2. 管理员不得恶意获取玩家物品。
  3. 管理员不得无理由破坏玩家建筑。
  4. 管理员不得利用权限谋取个人利益。

六、Bug 与漏洞

6.1 Bug 使用

发现服务器 Bug 后：

  1. 不得利用 Bug 获取大量资源或经济。
  2. 不得向其他玩家传播恶意利用方法。
  3. 应向管理员或腐竹报告。

Bug 举报方式：

  • QQ群：1093697834
  • 游戏内：找管理员或腐竹，如果没有请看上下
  • 邮箱：zl240712@outlook.com

6.2 Bug 利用处罚

第一次：警告

第二次：ban 一周

严重情况：飞机票，永久黑名单

七、违规处罚

由违反的情况与严重程度进行群成员、群管理员和腐竹的投票进行权衡。

处罚类型有以下几种情况：

  1. 警告
  2. 禁言
  3. 踢出服务器
  4. 临时封禁
  5. 永久封禁，并加入黑名单
  6. 没收违规获得的物品
  7. 回滚违规行为

八、封禁与申诉

8.1 封禁规则

封禁时间由违反的情况与严重程度进行群成员、群管理员和腐竹的投票进行权衡。

8.2 申诉

玩家如果认为处罚存在错误，可以通过以下方式申诉：

备份周期：一个月

服务器出现严重故障时：

紧急暂停，并在官方群发布通知。修复结束时间会根据严重程度进行动态调整。

十、特殊规则

当前暂无额外特殊玩法规则。

十一、最终说明
